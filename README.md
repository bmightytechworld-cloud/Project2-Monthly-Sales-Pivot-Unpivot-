## Monthly Sales Data — Cleaning, Pivot and Unpivot

## What The Data Was About
Monthly sales records for a retail business tracking 
product revenue across regions by sales rep

## Problems Found
- Inconsistent month names (february, FEBRUARY, February)
- Inconsistent region and product names
- Inconsistent sales rep names
- Missing units sold values
- Duplicate rows

## What I Fixed
- Standardized all month, region and product names
- Removed all duplicates
- Handled all missing values
- Created pivot view — products as columns for easy comparison
- Created unpivot view — long format ready for charts and analysis

## Deliverables
- Sheet 1 — Raw messy data
- Sheet 2 — Full clean table
- Sheet 3 — Pivot view
- Sheet 4 — Unpivot view

## Tools Used
Microsoft Excel — Power Query
